Detailed Description

Cross-platform UDP socket driver interface.

This module provides a platform-independent abstraction for UDP datagram communication. It allows higher layers (transport, protocol stack, FSM, etc.) to communicate over UDP without dealing with OS-specific socket APIs.

Supported platforms:

  • Linux / POSIX sockets
  • Windows / WinSock

The driver provides APIs for:

  • Opening a UDP socket and binding to a local port
  • Closing the socket
  • Transmitting datagrams to a remote peer
  • Receiving datagrams from a remote peer

Because UDP is connectionless, the remote peer address is stored inside the driver context at open time and reused by every drv_udp_tx() call. drv_udp_rx() accepts datagrams from any sender; the source address of the last received datagram is cached in drv_udp_t::peer so that replies can be sent back with drv_udp_tx().

Example usage:

drv_udp_t udp;
if (drv_udp_open(&udp, "192.168.1.100", 9000) == 0)
{
uint8_t msg[] = "HELLO";
drv_udp_tx(&udp, msg, sizeof(msg));
uint8_t buffer[128];
int len = drv_udp_rx(&udp, buffer, sizeof(buffer));
drv_udp_close(&udp);
}
