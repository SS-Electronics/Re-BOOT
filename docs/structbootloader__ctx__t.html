Detailed Description

Runtime context shared across all FSM states.

This structure is allocated in main.c, initialised before the FSM starts, and passed as user_data so every action function can reach it via CTX(fsm).

Members that come from the target (sector_size, segment_size) are filled in by act_target_info once the target responds with its hardware parameters.

◆ node_id

int bootloader_ctx_t::node_id

Target node identifier supplied via the -n command-line option.

Sent as the second byte of CMD_RESET_REQ so the target bootloader can verify it is the intended recipient. The target echoes this value back in RESP_TARGET_INFO (byte 8); act_target_info validates the echo and aborts if there is a mismatch.
