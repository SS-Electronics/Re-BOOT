Detailed Description

Communication and packet handling subsystem.

This module manages packet communication between the host and the target system using a transport abstraction layer.

Responsibilities include:

  • Receiving packets from transport drivers
  • Maintaining sliding window state
  • Pushing packets to processing queues
  • Supporting concurrent RX thread execution

void * comm_rx_thread ( void *  arg)

Communication RX thread.

This thread continuously receives packets from the transport layer and forwards them to the system processing queue.

Typical workflow:

  • Wait for incoming packets from transport
  • Allocate packet structure
  • Push packet to RX queue
  • Signal processing subsystem

This thread runs concurrently with the main application and other worker threads.

Parameters
argOptional user argument (unused in most cases).
Returns
Pointer return value required by thread interface.

Communication RX thread.

Runs continuously until *thread_running_flag is cleared. On each iteration it blocks inside transport_receive() until either a complete packet arrives or the thread is asked to stop.

Happy path (one iteration)
  1. transport_receive() returns a positive payload length.
  2. A comm_packet_t is allocated on the heap.
  3. The received packet is copied into the heap allocation.
  4. The pointer is pushed into handle_queue_receive_packets.
  5. Loop back to step 1.
Error path
  • Return value -3 means the payload length field in the frame exceeded COMM_MAX_DATA. The parser has already reset itself.
  • Return value -5 means the CRC16 did not match. The parser has already reset itself.
  • Both cases are logged and the loop continues immediately.
  • Return value -1 means the thread stop flag was cleared; the loop exits.
Parameters
argPointer to an int32_t thread-running flag. The thread exits when *arg becomes 0.
Returns
NULL always (required by the thread interface).
Note
The consumer of the queue (act_fsm_signal_generation) must call free() on every packet pointer it pops, otherwise heap memory will be leaked.
