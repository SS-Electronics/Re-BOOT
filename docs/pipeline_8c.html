Detailed Description

Firmware transfer pipeline — sector organisation and segment extraction for the Re-BOOT host application.

This module converts a flat array of parsed Intel HEX records into a set of flash-sector-aligned data buffers (the "pipeline"). Once built, the pipeline is consumed segment by segment during the firmware upload sequence.

Data model
pipeline_builder_t
└── sectors[] (dynamically grown with realloc)
└── sector_pipeline_t
├── data[] (sector_size bytes, 0xFF where unprogrammed)
└── valid[] (sector_size bytes, 1 = byte was in the HEX file)

Find or create the sector that owns addr.

Walks the existing sector array looking for a sector whose base address matches the one computed from addr. If no match is found a new sector_pipeline_t is appended via realloc and initialised with 0xFF data and zeroed valid map.

Build the sector pipeline from an array of HEX records.

Iterates over every record and calls insert_record() to place data bytes into sector-aligned buffers. After this call the builder's sectors array contains one entry per distinct flash sector touched by the firmware image, sorted in the order the sectors were first encountered in the HEX file.

Fetch the next segment from a sector for transmission.

Scans forward from *offset within the sector identified by sector_index, skipping any leading invalid (unprogrammed) bytes. Once a valid byte is found, up to seg bytes are copied into data and the absolute flash address of the first byte is written to addr.

*offset is advanced by the number of bytes returned, so repeated calls automatically walk through the entire sector.

Parameters
pbPointer to the pipeline builder.
sector_indexIndex of the sector to read from.
offsetIn/out: byte offset within the sector. Advanced by the number of bytes returned.
segMaximum segment size (bytes) to copy.
addrOutput: absolute flash address of the first byte.
dataOutput buffer; must be at least seg bytes.
Returns
Number of bytes copied into data (1 … seg), or -1 if no more valid bytes remain in the sector.

Compute the CRC32 checksum of a complete sector.

Calculates a standard CRC32 (polynomial 0xEDB88320, reflected, initial value 0xFFFFFFFF, final XOR 0xFFFFFFFF) over the entire sector data buffer including bytes marked invalid (which hold the 0xFF erase value). This matches what the target will compute after it reads back the programmed sector from flash.

Parameters
pbPointer to the pipeline builder.
sector_indexIndex of the sector to checksum.
Returns
CRC32 of the sector's data buffer.
