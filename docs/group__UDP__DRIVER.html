Detailed Description

Cross-platform UDP datagram communication driver.

This module implements a UDP socket abstraction used by communication frameworks or transport layers.

Open a UDP socket.

Creates a UDP socket, resolves the remote peer address, and binds to an ephemeral local port so that incoming datagrams can be received.

Parameters
[in,out]ctxPointer to UDP driver context.
[in]ipRemote peer IP address (example: "192.168.1.10").
[in]portRemote peer UDP port.
Returns
int
Return values
0Socket opened successfully
-1Failed to create or configure socket

Creates a UDP datagram socket, resolves the remote peer address from ip and port, stores it in ctx->peer for use by drv_udp_tx(), and sets a receive timeout of 100 ms so that drv_udp_rx() behaves non-blocking under normal operation.

Receive a UDP datagram.

Reads one datagram from the socket into the provided buffer. The source address of the received datagram is cached in ctx->peer so that a subsequent drv_udp_tx() replies to the correct sender.

Parameters
[in]ctxPointer to initialized UDP driver context.
[out]bufferBuffer to store received data.
[in]max_lenMaximum number of bytes that can be stored in buffer.
Returns
int
Return values
>0Number of bytes received
0No data (non-blocking socket returned immediately)
-1Receive error

Reads one incoming datagram from the socket into buffer. The source address of the received datagram is updated in ctx->peer so that a subsequent drv_udp_tx() call replies to the correct sender.

The socket has a 100 ms receive timeout configured by drv_udp_open(), so this call returns 0 (no data) rather than blocking indefinitely when no datagram arrives.
