Open a file.

This function opens a file using the specified mode and initializes the file handle inside the file object.

Supported modes:

  • FILEIO_WRITE : Creates a new file or truncates an existing file.
  • FILEIO_APPEND : Opens an existing file and appends data to the end.

The file is opened in binary mode to ensure consistent behavior across Linux and Windows platforms.

Parameters
fPointer to the file object that will store the file handle.
pathPath to the file to be opened.
modeFile opening mode (write or append).
Returns
  • 0 : File opened successfully.
  • -1 : Failed to open file.
Note
The caller must close the file using fileio_close() when finished.

Write formatted text.

This function behaves similarly to printf(), but instead of writing directly using vfprintf(), it first formats the output into an intermediate buffer and then writes the buffer using fileio_write().

This design ensures that all file output goes through the same low-level write mechanism (fwrite), which can simplify logging, buffering, and debugging in system frameworks.

Parameters
fPointer to the file object.
fmtFormat string (same syntax as printf).
Returns
Number of bytes written to the file.
Return values
-1Returned if the file handle is invalid.
Note
The formatted string size is limited by the internal buffer.
