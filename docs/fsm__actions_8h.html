Handle a sector write NACK and initiate a retry.

Called when RESP_CRC_NACK is received. Increments the retry counter and, if the limit has not been reached, resets the sector offset to 0 and dispatches EVT_START to retransmit the entire sector from the beginning.

If retry_count reaches max_retries the FSM is halted by clearing fsm->fsm_running.

◆ act_fsm_signal_generation()

void act_fsm_signal_generation ( fsm_t *  fsm)

Poll the RX queue and dispatch FSM events.

Called from the main loop on every iteration. Dequeues one packet, maps its command byte to the appropriate event, and dispatches it.

Command → event mapping

  • RESP_TARGET_INFO + node_id → EVT_TARGET_INFO (packet in event data)

    The node ID is encoded in the command byte. A packet whose command byte does not equal RESP_TARGET_INFO + node_id is silently discarded — it belongs to a different node on the bus.

  • RESP_SEG_ACK → EVT_SEG_ACK
  • RESP_CRC_ACK → EVT_CRC_OK
  • RESP_CRC_NACK → EVT_CRC_NACK
  • RESP_APP_JUMP_ACK → EVT_APP_ACK
Parameters
fsmPointer to the bootloader FSM instance.
Note
The dequeued packet is always freed after event dispatch.

Transmit one firmware segment to the target.

Calls pipeline_next_segment() to fetch the next chunk of data from the current sector and sends it as a CMD_PIPELINE_DATA packet.

If the sector is exhausted (no more segments), EVT_SECTOR_END is dispatched to trigger CRC verification.

The FSM remains in ST_SEND_WINDOW and waits for the target to reply with RESP_SEG_ACK before the next segment is sent.

Parse target information and initialise the context.

Extracts flash start address, sector size, and segment size from the 8-byte payload and stores them in bootloader_ctx_t. Dispatches EVT_START to trigger pipeline construction.

Payload layout
Byte 0–3 : Flash start address (big-endian uint32)
Byte 4–5 : Sector size in bytes (big-endian uint16)
Byte 6–7 : Segment size in bytes (big-endian uint16)

Node ID filtering is performed upstream in act_fsm_signal_generation by matching the command byte against RESP_TARGET_INFO + node_id, so by the time this function is called the packet is already confirmed to belong to the correct node.
