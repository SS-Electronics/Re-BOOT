Detailed Description

Cross-platform TCP driver implementation.

This module implements the TCP socket abstraction defined in drv_tcp.h. It allows the transport layer to communicate using TCP sockets without dealing with platform-specific APIs.

Supported platforms:

  • Linux / POSIX sockets
  • Windows / WinSock
